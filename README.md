### 🧩 Customer Retention Intelligence & Revenue Risk Dashboard

> A full-scale churn intelligence platform that goes beyond simple predictions — it delivers **business-actionable insights** through revenue risk scoring, cohort breakdowns, and a live retention dashboard.

<details>
<summary>📌 <strong>Project Deep Dive</strong></summary>

<br/>

- **Problem**: Raw churn rates don't tell businesses *where* they're losing revenue or *who* to re-engage first
- **Solution**: XGBoost churn model layered with revenue-weighted risk scores and cohort-level analysis
- **Key Features**:
  - 📉 Churn probability per customer with explainability (SHAP values)
  - 💰 Revenue-at-risk scoring to prioritize high-value customers
  - 📊 Cohort retention heatmaps and drop-off visualization
  - 🖥️ Streamlit dashboard with Plotly interactive charts
- **Impact**: Enables data-driven retention decisions without needing a data analyst in the loop

</details>

### 🖐️ HandSafeNet — Hand Gesture Safety Detection

> Real-time hand gesture recognition and **safety classification** system, combining a custom-trained CNN with geometric distance mapping for robust gesture identification.

<details>
<summary>📌 <strong>Project Deep Dive</strong></summary>

<br/>

- **Problem**: Existing gesture systems lack safety-aware classification for human-machine interaction
- **Solution**: Custom CNN trained on hand landmark data with Euclidean Distance-based gesture comparison
- **Key Features**:
  - 🎯 Real-time hand detection via OpenCV
  - 🤖 Custom CNN architecture for gesture classification
  - 📐 Euclidean Distance mapping for geometric gesture validation
  - ✅ Safety/unsafe gesture labeling in live video feed
- **Impact**: Applicable in robotics, accessibility tools, and industrial safety monitoring

</details>

<br/>

### 🚦 Traffic Signal Optimization using ML

> An intelligent traffic management system combining **Genetic Algorithms** for signal timing and **Random Forest** for real-time flow prediction — deployed as a Flask API.

<details>
<summary>📌 <strong>Project Deep Dive</strong></summary>

<br/>

- **Problem**: Static signal timings lead to inefficient traffic flow and increased congestion
- **Solution**: GA-optimized signal timing + RF-based real-time prediction, served via REST API
- **Key Features**:
  - 🧬 Genetic Algorithm evolves optimal signal timing per intersection
  - 🌲 Random Forest predicts vehicle flow from historical + real-time data
  - 🌐 Flask API for real-time integration with traffic management systems
  - 📊 Performance benchmarked against fixed-time and round-robin baselines
- **Impact**: Demonstrated significant reduction in average vehicle wait time in simulation

</details>
